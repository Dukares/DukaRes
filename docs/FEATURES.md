# DukaRes Features

## Core Features

### Direct Bookings

Allow guests to book directly without relying on third-party marketplaces.

### Property Management

Manage hotels, apartments, villas, resorts and vacation rentals.

### Availability Control

Centralized availability management for all properties.

### Booking Management

Create, manage and monitor reservations from a single dashboard.

### Payments

Support for secure online payments.

### Multi Property Support

Manage multiple properties from one account.

### User Roles

Support for owners, staff and administrators.

### Reporting

Access booking and business performance information.
