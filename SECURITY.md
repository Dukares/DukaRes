# Security Policy

## DukaRes Security

Security is a core principle of the DukaRes project.

The platform is currently under active development and continuous improvement.

---

## Reporting Security Issues

If you discover a security vulnerability, please report it privately.

Do not publish security vulnerabilities publicly.

Contact:

info@bookingalbania.net

---

## Scope

This repository contains public project documentation only.

Internal implementation details, proprietary business logic, infrastructure configuration, and private components are not included in this repository.

---

## Responsible Disclosure

Please provide:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

All valid reports will be reviewed.

---

## Status

DukaRes is currently under active development.

Security reviews and improvements are performed continuously as the platform evolves.
